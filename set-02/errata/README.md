# set-02 정정 원본 — 세트 귀속 안내

`errata/` 안의 txt 는 **원본이라 수정하지 않는다.** 이 파일은 어느 항목이 이 세트 몫인지만 정리한다. 판정 근거와 반영 내역은 [`../task-1/NOTES.md`](../task-1/NOTES.md) 정정 로그에 있다.

## 이 세트의 정본

| 파일 | 내용 |
|---|---|
| `질의 답변.txt` | 1-1-A `/242`→`/24`, 2-1-A 버킷 비번호 채점 제외, 7-2 ALB 예상 출력 |
| `질의 답변(1).txt` | 10-0 Grafana 접속 게이트 신설 + 10-1~4 재정의, 1-1-A, 2-1-A, `[7]` DynamoDB GSI |

이 둘이 set-02 정정의 전부다. **`수정사항.txt` 는 이 디렉터리에 없다** — set-03 정정본이라 [`../../set-03/errata/수정사항(1).txt`](../../set-03/errata/수정사항(1).txt) 로 옮겼다(2026-08-16).

## `질의답변-취합-20260816.txt` — 두 세트가 섞인 문서

심사장 공유 자료 기반 선수 취합본이라 set-02 와 set-03 항목이 한 파일에 들어 있다. **이 세트 몫만 아래 6건이다.**

| 취합본 항목 | 이 세트 번호 | 판정 |
|---|---|---|
| `[1-1-A]` Subnet Prefix `/242`→`/24` | 1-1-A | 영향없음 (구현·전사본 모두 이미 `/24`) |
| `[2-1-A]` 버킷 이름 비번호 채점 제외 | 2-1-A | 수정완료 (채점지 전사본) |
| `[7]` DynamoDB GSI 요구사항 명시 | 4-1-A / 9-2-A | 수정완료 (과제지 전사본) |
| `[7-2]` ALB 규칙 예상 출력 | 7-2-A | 영향없음 |
| `[10-1~4 (12)]` Grafana 메트릭 범위 | 10-1~4 | Pod 개수 패널만 book app 한정 |
| `01` Grafana 파드 범위(All Pod) | 10-1~4 | 정본(book app)과 충돌 — 정본 우선, 4패널은 양쪽 통과하게 유지 |

나머지 항목(`11-x`, `6-1` S3 KMS, `9-3` `created_at`, `5-4`, App Logs, DataSource)은 **set-03 몫**이다. 이 세트 채점지는 대분류 1~10 이고 11절·Alert·로그 형식·DataSource 항목이 없다. → [`../../set-03/errata/README.md`](../../set-03/errata/README.md)

## 미해결

`9-2-A` 예상 출력이 `created_at`·`booking_id` 포함 고정 문자열에 "정확히 일치" 판정인데, **이를 완화하는 답변이 이 세트엔 없다.** `booking_id` 는 예시값이라는 답변도, `created_at` 을 `date` 기준 1분 이내로 본다는 답변도 전부 set-03 정정본의 내용이다. 대회 당일 심사장 확인 사항.
