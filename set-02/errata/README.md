## 2026-08-21 신판 배부 후 — 어느 정정이 아직 살아 있나

출제자가 문제지·채점기준표를 재배부했다(`task.pdf`·`mark.pdf` 는 신판으로 교체). 위 두 txt 의
항목 중 일부는 신판 본문에 흡수돼 더는 "정정"이 아니고, 일부는 **신판에서도 안 고쳐져 계속 유효**하다.

| 정정 항목 | 신판 상태 | 대회 당일 대응 |
|---|---|---|
| 2-1-A 버킷 비번호 채점 제외 | **흡수** — 예상 출력이 `wskorea26-concert-bucket-<선수비번호>` 로 바뀌었다 | 조치 불필요 |
| `[7]` DynamoDB GSI | **흡수** — 문제지 §7 에 GSI 줄이 들어갔다 | 조치 불필요 |

[`../task-1/NOTES.md`](../task-1/NOTES.md) 의 2026-08-21 정정 로그에 있다.

심사장 공유 자료 기반 선수 취합본이라 set-02 와 set-03 항목이 한 파일에 들어 있다. **이 세트 몫만 아래 6건이다.**

| 취합본 항목 | 이 세트 번호 | 판정 |
|---|---|---|
| `[1-1-A]` Subnet Prefix `/242`→`/24` | 1-1-A | 영향없음 (구현·전사본 모두 이미 `/24`) |
| `[2-1-A]` 버킷 이름 비번호 채점 제외 | 2-1-A | 수정완료 (채점지 전사본) |

## 미해결

`9-2-A` 예상 출력이 `created_at`·`booking_id` 포함 고정 문자열에 "정확히 일치" 판정인데, **이를 완화하는 답변이 이 세트엔 없다.** `booking_id` 는 예시값이라는 답변도, `created_at` 을 `date` 기준 1분 이내로 본다는 답변도 전부 set-03 정정본의 내용이다. 대회 당일 심사장 확인 사항.
