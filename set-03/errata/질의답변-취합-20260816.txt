## 2. 세부 항목

### [1-1-A] Subnet Prefix 오타 수정
- wskorea26-pub-subnet-d Subnet의 Prefix 표기 오기 /242 를 /24 로 정정.

### [2-1-A] S3 버킷 이름의 비번호 처리
- S3 버킷 이름 생성 조건에서 <비번호>가 특정 번호(103)로 고정 기재된 문제.
- 조치: <비번호> 부분은 채점 대상에서 제외.

### [6-1] S3 KMS 암호화 검증 기준 수정
- aws s3api list-objects --prefix "static/" 실행 시 조회되지 않는 static/ PASS 객체는 채점 대상에서 제외.

### [7] DynamoDB GSI 요구사항 명시
- concert_name 조회 및 created_at 기준 최신순 정렬용 GSI를 과제지에 추가 명시.
  - Index Name: concert_name-created_at-index
  - Partition Key: concert_name
  - Sort Key: created_at

### [7-2] ALB 규칙 채점 기준 수정
- ALB 규칙의 예상 출력값은 최신 채점지 기준으로 채점.
- 예상 출력값:
  wskorea26-cf
  wskorea26-cf
  403

### [9-3] created_at 시간 검증 기준
- created_at 값이 요청 시점으로부터 1분 이내 생성인지 검증할 때, curl 요청 직전의 시스템 시간(date)을 기준으로 판별.

### [App Logs] 애플리케이션 로그 채점 기준
- 예시 화면에 요구사항 외 다른 로그가 포함되어 있더라도, 과제지 및 채점기준표에 명시된 규격 로그 형식 및 조건을 기준으로 채점.

### [5-4 / 11-1 / 11-3] 테스트 Pod 및 Alert 관련 채점 방식 변경
- 11-1-A: Pod 생성 단계를 채점 대상에서 제외.
- 11-3-A: Alert 검증에 필요한 Pod 생성 및 sleep 구문 실행은 수동으로 진행.
- 테스트 리소스 생성으로 인해 기존 Pod 조회 결과나 Alert 상태가 변동되더라도 재채점 기준으로 사용하지 않음.

### [10-1~4 (12)] Grafana 메트릭 대상 범위 구체화
- book app Pod 대상 5개 메트릭 지표: CPU 사용량, Memory 사용량, Pod 개수, 컨테이너 재시작 횟수, 네트워크 트래픽 수신량.

### [11-3] Grafana Pod 모니터링 범위
- Pod CPU/Memory 모니터링 패널은 특정 Pod 한정이 아니라 모든 Pod(All Pod) 대상.

### [11-3] Grafana 패널명 및 시각화 채점 기준
- 패널 이름(Panel Name)은 채점 대상이 아님.
- 과제지 Description에 제시된 메트릭 및 로그 데이터의 정확한 추출·표현 여부 중심 채점.
