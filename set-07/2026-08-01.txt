=== 1과제 ===

먼저, 수정 필요하지 않은 사항부터 답변드립니다.

1) Platform MRK 관련
선수 유의사항 7번에 모든 리소스는 '서울' 리전에 구성하도록 지시하고 있으며, us-east-1 MRK로 구성하라는 과제지의 지시의 경우, 기본적으로 선수 유의사항을 준수하여 Primary를 서울 리전에 구성하되, MRK로 구성하여 us-east-1에서 사용 가능하도록 하라는 지시로 해석해주시면 될 것 같습니다.

수정된 사항에 대한 답변입니다.

1) KMS key wildcard policy 관련
리소스에 대해서는 와일드카드 제한을 해제하는 것으로 수정하였습니다.

2) Timezone 관련
해당 issue의 경우, 현재 모든 채점지의 tz 표기를 수정하는게 어려운 상황이기에 채점기준표에는 채점지가 UTC로 표기되어 있으나, 채점 시에는 KST 기준으로 확인할 것으로 지시하도록 하였습니다. 동시에 2과제에서도 같은 issue 있어 추가해두었습니다.
또한, 과제지에는 KST 기준으로 풀이를 지시하고 있는 점 참고 부탁드립니다.

3) WAF Managed Rules의 Response override 관련
CloudFront custom error response를 사용하면 Rule level override 없이도 이를 구현할 수는 있는 걸로 확인하였으나, 이는 과제의 의도에서 벗어난다고 생각되어 필요할 경우 Custom response 지정을 위해 override를 허용한다는 내용으로 변경하였습니다.

4) DynamoDB GSI와 Lambda API Spec 관련
말씀주신 Lambda의 경우, 과제지의 논리적 오류임을 발견하였으며, "Lambda를 통한 예약 조회를 지원하기 위해" 문장을 삭제하였습니다. 다만, 8-3, 8-4 채점 항목의 경우 booking_id를 추출하여 request를 진행하는 채점을 진행하고 있어, 이를 수정할 시 side effect가 발생할 수 있음에 따라 해당 표현을 수정하는 점 양해 부탁드립ㄴ다.
