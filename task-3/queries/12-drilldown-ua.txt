# [조사 2단계] UA 드릴다운 — 한 UA가 몇 개 IP에 분산돼 있고 무엇을 요청하며 어떤 룰에 걸리는지.
# 언제: 10에서 의심 UA를 찾았을 때, 또는 부하 생성기 UA가 차단되는지 확인할 때.
# 입력: {{target_ua}} (저장 쿼리 파라미터, 부분 문자열 매칭. 연습 시 예시: "gobuster", "ZAP", "WPScan")
# 다음: 단일 IP 집중이면 11(IP 드릴다운), 정상 서비스 UA가 걸렸으면 15(오탐 후보).
parse @message '"name":"User-Agent","value":"*"' as ua
| filter ua like {{target_ua}}
| stats count() as requests, sum(strcontains(action, "BLOCK")) as blocked, count_distinct(httpRequest.uri) as uriVariety by httpRequest.clientIp, terminatingRuleId
| sort requests desc
| limit 25
