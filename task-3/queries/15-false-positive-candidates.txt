# [조사 최종] 오탐 후보 — 정상 경로로 향한 요청이 BLOCK된 것을 룰·경로·메서드별로 집계.
#   요청 처리량이 채점 대상이므로 여기 잡히는 건수 = 진행 중인 감점 후보. 최우선 확인.
# 언제: 14에서 매칭 원문이 정상 트래픽처럼 보일 때, BLOCK 증가와 처리량 하락이 동시에 보일 때.
# 입력: <NORMAL_PATHS> 를 당일 실제 라우팅 경로 prefix regex로 치환 (13과 동일 값).
#   연습 시 예시: ^\/(v1\/(user|product|stress)|images\/)
# 다음: 오탐 확정 → 해당 룰 sensitivity 하향·스코프 축소·COUNT 강등 (NOTES.md 룰 설계안 참조).
filter action = "BLOCK" and httpRequest.uri like /<NORMAL_PATHS>/
| stats count() as blocked, min(@timestamp) as firstSeen, max(@timestamp) as lastSeen by terminatingRuleId, httpRequest.httpMethod, httpRequest.uri
| sort blocked desc
