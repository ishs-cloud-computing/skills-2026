# [조사] 존재하지 않는 경로 스캔 — 정상 경로 목록 "밖"의 모든 요청 (역-화이트리스트).
#   WAF가 ALLOW로 통과시켜 ALB 404 규칙으로 떨어지는 요청도 여기서 잡힌다.
# 언제: 상시 세트에서 미지의 uri가 보일 때, 또는 ALB 4xx 증가 시.
# 입력: <NORMAL_PATHS> 를 당일 실제 라우팅 경로 prefix regex로 치환.
#   연습 시 예시: ^\/(v1\/(user|product|stress)|images\/)
# 다음: 스캔 IP → 11(IP 드릴다운). ALLOW로 통과 중인 스캔 경로는 WAF 룰 추가 후보 → NOTES.md 룰 설계안.
filter httpRequest.uri not like /<NORMAL_PATHS>/
| stats count() as requests, sum(strcontains(action, "BLOCK")) as blocked by httpRequest.uri, httpRequest.clientIp
| sort requests desc
| limit 50
